# Horizon Bank – Core Banking System

Horizon Bank is a console-based core banking application developed using **PHP and MySQL**. The system manages customer information and performs essential banking operations, including credit and debit transactions, customer record management, and balance inquiries.

The project uses **Object-Oriented Programming (OOP)** concepts in PHP and MySQL database connectivity through MySQLi to organize the application logic and manage customer financial records.

## Features
- **Customer Management:** Insert, view, update, and delete customer records (CRUD operations).
- **Credit Operations:** Deposit money into a customer's account.
- **Debit Operations:** Withdraw money from a customer's account with balance validation.
- **View All Customers:** Display details of all registered customers.
- **Customer Details:** Retrieve specific customer information using their customer ID.
- **Balance Inquiry:** Check the available balance of a specific customer.
- **Database Integration:** Store and retrieve customer and transaction data using MySQL.
- **Transaction Handling:** Use database transactions to maintain data consistency during credit and debit operations.

## Technologies Used
- PHP
- MySQL
- MySQLi
- Object-Oriented Programming (OOP)
- SQL

## Project Objective
The objective of this project is to demonstrate practical knowledge of PHP, MySQL database operations, OOP principles, CRUD functionality, and basic banking transaction logic through a console-based application.

**Application Type:** Console-Based Banking System  
**Project Name:** Horizon Bank Core System
